## What's new

- **New actions: First page and Last page** of the open note or document. Thanks to **@jvita** for the idea (#2).
- **Fix:** a gesture that got stuck (a dialog that could not show, a file that would not open) no longer blocks every gesture after it. Swipes were recognised but did nothing.
- **Lighter:** Swipe no longer queries the system on every pen stroke.

Install: copy `Swipe.snplg` to `MyStyle`, then **Settings → Apps → Plugins → Add plugin**. Your settings are kept.
